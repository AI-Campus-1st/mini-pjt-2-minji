### 데이터베이스 테이블 구조

본 프로젝트에서는 수집한 상품 데이터를 효율적으로 관리하고 분석하기 위해 카테고리, 상품, 랭킹 정보를 각각의 테이블로 분리하여 저장하였다.  
또한 수집한 원본 데이터와 정제 및 점수 계산이 완료된 데이터를 별도의 CSV 파일로 관리하였다.


#### 기준 시점

- 데이터 기준일: 2026년 9월 6일
- Glowpick 랭킹은 매주 일요일 업데이트되며, 해당 기준일의 데이터를 수집하여 사용하였다.


#### 1. tb_category

카테고리 정보를 관리하는 테이블이다.

**주요 컬럼**

- `category_id`: 카테고리 고유 번호
- `name`: 카테고리 이름

**입도**

- 카테고리 1개당 1행

**테이블 목적**

- 베이스, 아이, 립 메이크업 카테고리를 구분하기 위해 사용한다.


#### 2. tb_product

상품의 기본 정보를 관리하는 테이블이다.

**주요 컬럼**

- `product_id`: 상품 고유 번호
- `category_id`: 상품이 속한 카테고리 번호
- `brand`: 브랜드명
- `name`: 상품명

**입도**

- 상품 1개당 1행

**테이블 목적**

- 상품별 카테고리, 브랜드, 상품명 등의 기본 정보를 저장한다.


#### 3. tb_ranking

상품별 랭킹 변화와 소비자 반응, 프로모션 우선 검토 점수를 관리하는 테이블이다.

**주요 컬럼**

- `product_id`: 상품 고유 번호
- `update_date`: Glowpick 랭킹 업데이트 날짜
- `current_rank`: 현재 순위
- `previous_rank`: 전주 순위
- `rank_change`: 전주 대비 순위 변화
- `rating`: 평점
- `review_count`: 리뷰 수
- `price`: 가격
- `score`: 프로모션 우선 검토 총점

**입도**

- 상품 1개 × 기준일 1일당 1행

**단위**

- `current_rank` / `previous_rank`: 순위
- `rank_change`: 순위 변동 폭
- `rating`: 점 (5점 만점)
- `review_count`: 건
- `price`: 원
- `score`: 점 (100점 만점)

**테이블 목적**

- 상품별 현재 순위와 전주 순위를 저장하여 순위 변화를 확인한다.
- 기준일별 평점, 리뷰 수, 가격 등의 정보를 저장한다.
- 프로모션 우선 검토를 위한 최종 점수를 저장한다.
