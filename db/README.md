### 데이터 베이스 테이블 구조

본 프로젝트에서는 수집한 상품 정보를 관리하기 위해 원본 csv 파일과 필요한 정보를 정제하고 계산한 csv 파일을 띠로 분리헤서 사용하였다.

#### 테이블 설명
1. tb_category
주요 컬럼 
- category_id : 카테고리 번호
- name : 카테고리 이름

- 카테고리 정보를 관리하는 테이블
- 베이스, 아이, 립 메이크업 카테고리를 구분하기 위해서 사용

2. tb_product
주요 컬럼
* produxt_id : 상품 고유 ID
*

- 상품의 정보를 관리하는 테이블
- 상품별 브랜드, 상품명, 용량, 상품 번호 정보 저장

3. tb_ranking
주요 컬럼
* produxt_id : 상품 고유 ID

- 상품의 순위를 관리하는 테이블
- 상품의 랭킹, 업데이트 날짜, 현재 순위, 전주 순위, 전주 대비 순위 변화, 평점, 리뷰수, 가격, 프로모션 우선 검토 총점 정보 저장
